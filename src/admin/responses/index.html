Simulated modes send that crawler's User-Agent string from Cloudflare's network. They show what this site returns to that User-Agent; they are not requests from OpenAI, Anthropic, Perplexity or Google. Real crawlers come from their own IP ranges and are identified by Cloudflare's bot detection, so bot rules (for example blocking AI crawlers) can treat them differently.
